# SCENE 01 — MULAI DARI PROGRAM YANG BISA DIJALANKAN

## Visual

Buat file `BankingApp.java`:

```java
public class BankingApp {
    public static void main(String[] args) {
        System.out.println("Cube Banking");
    }
}
```

## Narasi

> “Di video sebelumnya kita sudah menjalankan program Java pertama. Sekarang kita pakai Java untuk membuat simulasi rekening.”

> “Rekening adalah tempat bank mencatat uang nasabah. Saldo adalah jumlah uang yang tersedia. Penarikan mengurangi saldo, sedangkan setoran menambahnya.”

> “Simpan kode ini di `BankingApp.java`. Nama file dan nama `BankingApp` di baris pertama harus sama.”

Sorot bagian kode sesuai penjelasan:

> “`class BankingApp` adalah tempat kita menaruh kode program ini. `public` berarti class tersebut bisa diakses dari luar class.”

> “`main` adalah tempat Java mulai menjalankan program. Seperti pada baris pertama, `public` membuatnya bisa diakses dari luar class.”

> “`static` membuat `main` bisa dijalankan langsung dari nama class. `void` berarti `main` tidak mengirim hasil balik.”

> “`String[] args` berarti daftar teks yang bisa kita kirim saat memulai program. Tanda `[]` menunjukkan bahwa daftar itu dapat berisi beberapa teks. Kali ini kita tidak mengirim apa pun.”

> “Kurung kurawal `{` dan `}` membatasi isi class dan isi `main`. Tanda `;` menutup satu instruksi.”

> “`System.out.println` menampilkan satu baris di terminal, yaitu jendela tempat kita mengetik perintah dan melihat hasil program. Teks yang ditampilkan ditulis di antara tanda petik.”

## Terminal

Jalankan dari folder tempat file disimpan:

```bash
javac BankingApp.java
java BankingApp
```

Hasil:

```text
Cube Banking
```

## Narasi

> “`javac` memeriksa kode kita dan menghasilkan `BankingApp.class`, file yang bisa dijalankan Java. Lalu `java BankingApp` menjalankannya. Nama setelah `java` adalah nama class, tanpa `.java`.”

# SCENE 02 — SIMPAN DATA REKENING

## Visual

Ganti isi `main` dengan:

```java
String accountName = "Oskhar";
int balance = 1_000_000;
int withdrawal = 250_000;

System.out.println("Saldo awal " + accountName + ": " + balance);
```

Hasil:

```text
Saldo awal Oskhar: 1000000
```

## Narasi

> “Sekarang program punya tiga data: nama pemilik rekening, saldo awal, dan jumlah yang ingin ditarik.”

Sorot `int balance = 1_000_000;`:

> “`balance` adalah variabel: nama yang kita pakai untuk menyimpan nilai dan memakainya lagi. `int` berarti nilainya bilangan bulat. Tanda `=` mengisi variabel dengan nilai di sebelah kanan.”

> “Garis bawah pada `1_000_000` hanya membantu kita membaca angkanya. Nilainya tetap satu juta. Di latihan ini jumlah uang ditulis sebagai rupiah bulat.”

Sorot `String accountName = "Oskhar";`:

> “`String` berarti teks. Jadi nama pemilik disimpan sebagai teks, sedangkan saldo dan jumlah penarikan disimpan sebagai bilangan bulat.”

Sorot baris `println`:

> “Saat `+` dipakai bersama teks, Java menyambung bagian-bagian itu menjadi satu baris. Itulah sebabnya nama dan saldo bisa muncul dalam satu keluaran.”

Tampilkan sesaat:

```java
int balance = "satu juta";
```

> “Kalau kita isi `int` dengan teks seperti ini, lalu jalankan `javac BankingApp.java`, Java akan menolak karena jenis datanya tidak cocok. Ini disebut kesalahan kompilasi: program belum berhasil dibuat untuk dijalankan.”

Kembalikan `balance` menjadi `1_000_000` sebelum lanjut.

# SCENE 03 — TENTUKAN APAKAH PENARIKAN BOLEH DILAKUKAN

## Visual

Di bawah baris yang menampilkan saldo awal, tambahkan:

```java
boolean canWithdraw = withdrawal > 0 && withdrawal <= balance;

if (canWithdraw) {
    balance = balance - withdrawal;
    System.out.println("Penarikan berhasil");
} else {
    System.out.println("Penarikan ditolak");
}
```

## Narasi

> “Sebelum mengurangi saldo, kita perlu memastikan jumlah penarikan lebih besar dari nol dan tidak melebihi saldo.”

Sorot kondisi:

```java
withdrawal > 0 && withdrawal <= balance
```

> “`>` berarti lebih besar dari. `<=` berarti lebih kecil atau sama dengan. Keduanya menghasilkan jawaban `true` atau `false`. Tanda `&&` berarti kedua syarat harus benar.”

> “Jawaban itu kita simpan di `canWithdraw`. Jenis datanya `boolean`, yaitu data yang hanya berisi `true` atau `false`.”

Sorot `if` dan `else`:

> “Kalau `canWithdraw` bernilai `true`, Java menjalankan bagian `if`. Kalau `false`, Java menjalankan bagian `else`.”

Sorot `balance = balance - withdrawal;`:

> “Di sini `-` mengurangi dua angka. Hasilnya dimasukkan lagi ke `balance`. Jadi saldo berubah dari satu juta menjadi tujuh ratus lima puluh ribu.”

## Visual: dua percobaan

| `withdrawal` | Syarat terpenuhi? | Hasil |
| ---: | :---: | --- |
| `250_000` | Ya | Penarikan berhasil; saldo `750_000` |
| `2_000_000` | Tidak | Penarikan ditolak; saldo tetap `1_000_000` |

## Narasi

> “Coba ubah `withdrawal` menjadi dua juta dan jalankan lagi. Penarikan ditolak, sehingga saldo tidak berubah. Setelah melihat hasilnya, kembalikan ke `250_000`.”

# SCENE 04 — ULANGI SETORAN BULANAN

## Visual

Di bawah bagian `if` dan `else`, masih di dalam `main`, tambahkan:

```java
int monthlyDeposit = 100_000;

for (int month = 1; month <= 3; month++) {
    balance = balance + monthlyDeposit;
    System.out.println("Saldo bulan " + month + ": " + balance);
}

System.out.println("Saldo akhir " + accountName + ": " + balance);
```

## Narasi

> “Sekarang ada setoran seratus ribu rupiah setiap bulan selama tiga bulan. Setoran berarti uang masuk, jadi kita menambahkannya ke saldo.”

Sorot baris `for` satu bagian setiap kali:

> “`for` mengulang kode di dalam kurung kurawal. `int month = 1` memulai hitungan dari bulan satu. `month <= 3` membuat pengulangan berjalan sampai bulan tiga. `month++` menambah nomor bulan satu setiap selesai satu putaran.”

> “Di sini `+` berada di antara dua bilangan bulat, jadi artinya penjumlahan. Pada baris `println`, `+` menyambung teks dengan nomor bulan dan saldo.”

## Visual: telusuri saldo

```text
Setelah penarikan: 750000
Bulan 1:           850000
Bulan 2:           950000
Bulan 3:          1050000
```

## Narasi

> “Setiap putaran memakai saldo hasil putaran sebelumnya. Setelah bulan tiga, syarat `month <= 3` tidak terpenuhi lagi, lalu program menampilkan saldo akhir.”

# SCENE 05 — BERI NAMA PADA PROSES PENARIKAN

## Visual

Sorot kode dari `boolean canWithdraw = ...` sampai kurung kurawal penutup `else` di dalam `main`. Hapus bagian itu, lalu ganti dengan satu baris:

```java
balance = withdraw(balance, withdrawal);
```

Tambahkan kode berikut setelah kurung kurawal penutup `main`, sebelum kurung kurawal penutup `BankingApp`:

```java
static int withdraw(int currentBalance, int amount) {
    boolean canWithdraw = amount > 0 && amount <= currentBalance;

    if (canWithdraw) {
        System.out.println("Penarikan berhasil");
        return currentBalance - amount;
    } else {
        System.out.println("Penarikan ditolak");
        return currentBalance;
    }
}
```

## Narasi

> “Pemeriksaan dan pengurangan saldo adalah satu pekerjaan: memproses penarikan. Kita beri pekerjaan itu nama `withdraw`.”

> “Bagian kode yang punya nama dan bisa dipanggil seperti ini disebut method. `main` juga method; Java menjalankannya pertama kali.”

Sorot baris pertama method:

> “`currentBalance` dan `amount` adalah dua nilai yang diterima method. Ketika kita memanggil `withdraw(balance, withdrawal)`, nilai `balance` masuk sebagai `currentBalance`, dan nilai `withdrawal` masuk sebagai `amount`.”

> “`int` sebelum `withdraw` berarti hasil method berupa bilangan bulat. `static` punya arti yang sama seperti pada `main`: kita bisa memanggil method ini langsung dari class yang sama.”

Sorot dua `return`:

> “Kalau penarikan boleh dilakukan, `return` mengirim saldo yang sudah dikurangi. Kalau ditolak, `return` mengirim saldo semula. Setelah `return`, method selesai.”

Kembali ke pemanggilan:

> “Hasil dari `withdraw` kita simpan lagi ke `balance`. Dengan begitu, setoran bulanan selalu memakai saldo yang benar.”

# SCENE 06 — JALANKAN PROGRAM UTUH

## Kode akhir: `BankingApp.java`

```java
public class BankingApp {
    public static void main(String[] args) {
        String accountName = "Oskhar";
        int balance = 1_000_000;
        int withdrawal = 250_000;

        System.out.println("Saldo awal " + accountName + ": " + balance);

        balance = withdraw(balance, withdrawal);

        int monthlyDeposit = 100_000;

        for (int month = 1; month <= 3; month++) {
            balance = balance + monthlyDeposit;
            System.out.println("Saldo bulan " + month + ": " + balance);
        }

        System.out.println("Saldo akhir " + accountName + ": " + balance);
    }

    static int withdraw(int currentBalance, int amount) {
        boolean canWithdraw = amount > 0 && amount <= currentBalance;

        if (canWithdraw) {
            System.out.println("Penarikan berhasil");
            return currentBalance - amount;
        } else {
            System.out.println("Penarikan ditolak");
            return currentBalance;
        }
    }
}
```

## Terminal

```bash
javac BankingApp.java
java BankingApp
```

Hasil yang diharapkan:

```text
Saldo awal Oskhar: 1000000
Penarikan berhasil
Saldo bulan 1: 850000
Saldo bulan 2: 950000
Saldo bulan 3: 1050000
Saldo akhir Oskhar: 1050000
```

## Narasi

> “Baca hasilnya dari atas. Saldo awal satu juta. Penarikan dua ratus lima puluh ribu berhasil, jadi saldo tersisa tujuh ratus lima puluh ribu. Tiga setoran menambah masing-masing seratus ribu. Saldo akhirnya satu juta lima puluh ribu.”

> “Kita mulai dari data, memakai syarat untuk menentukan penarikan, mengulang setoran, lalu memindahkan proses penarikan ke method yang punya nama.”
